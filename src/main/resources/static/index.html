Console de teste

Esta página consulta e altera dados reais da API. Use uma residência de teste para cadastrar, editar e excluir. O front-end React do grupo deve usar o mesmo contrato, disponível em docs/API.md.

Conexão

Por padrão, usa esta API. Para testar outra origem, ela precisa estar liberada no CORS.

Executar uma operação

As ações de escrita usam o banco configurado. Não há respostas simuladas nesta página.

Troque o ID da rota pela residência escolhida. Nas rotas aninhadas não envie cdResidencia no JSON. Para GET/DELETE, o corpo é ignorado.
